# Lisân Campus

**Lisân Campus** est une initiative indépendante des **Éditions Lisân**, conçue par **Mouhamadou CISSEMA** (Abidjan, Côte d'Ivoire).

Le site réunit deux espaces :

- **Droit · Licence 1** : les matières de la Licence 1 Droit de l'Université Musulmane Africaine (introduction au droit, droit civil, droit musulman, organisation judiciaire, méthodologie juridique, expression écrite, anglais, informatique), enrichies au fil des cours ;
- **Formation à l'IA avec Claude** : comprendre l'intelligence artificielle et maîtriser Claude pour étudier, travailler et produire, en toute sécurité. Ouverte à tous.

Chaque matière propose des leçons courtes, la lecture à voix haute, un quiz corrigé et des cartes de révision. Le site s'installe sur le téléphone comme une application et fonctionne hors connexion. La progression de chaque visiteur reste enregistrée sur son propre appareil.

Lisân Campus n'est pas un site officiel de l'Université Musulmane Africaine.

## Organisation du dépôt

| Fichier | Rôle |
|---|---|
| `site/index.html` | Le site complet (contenus, mise en page et fonctionnement) |
| `site/manifest.webmanifest` | Rend le site installable comme une application |
| `site/sw.js` | Lecture hors connexion |
| `site/icon-*.png`, `site/apple-touch-icon.png`, `site/favicon-32.png` | Icônes Lisân |
| `site/robots.txt` | Autorise les moteurs de recherche |
| `netlify.toml` | Publication sur Netlify (dossier `site`) |
